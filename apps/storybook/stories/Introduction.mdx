# UmrahHaji Design System

This workspace is scaffolded and empty on purpose.

- `packages/tokens` — the single source of truth for design tokens, built with
  Style Dictionary into CSS custom properties, JS/TS, and JSON.
- `packages/ui` — the React component library, bundled with Vite and styled
  with Tailwind.
- `apps/storybook` — this site, where every component is documented and checked
  with `@storybook/addon-a11y`.

Add token files under `packages/tokens/src` and components under
`packages/ui/src`; their stories are picked up automatically.
