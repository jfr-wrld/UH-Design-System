# Tooltip

Label tambahan singkat yang muncul saat trigger-nya di-hover atau di-focus -
untuk menjelaskan ikon atau kontrol yang maknanya tidak selalu jelas dari
tampilannya saja. `placement` otomatis flip ke sisi sebaliknya kalau ruang
viewport tidak cukup, dan `aria-describedby` menyambungkannya ke trigger
tanpa mengganti nama aksesibilitas trigger itu sendiri.
