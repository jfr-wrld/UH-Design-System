# Input

Kolom teks satu baris untuk data bebas - nama, nomor paspor, alamat email,
kata sandi. Label selalu ada di atas kolom, bukan mengambang di dalamnya:
audiens produk ini sering menyalin nomor paspor langsung dari dokumen fisik
sambil mengetik, dan label yang hilang begitu mereka mulai mengetik membuat
mereka kehilangan konteks di tengah jalan. `clearable`, penghitung karakter,
dan toggle password semuanya dibangun di atas `FieldShell` yang sama dipakai
`PhoneInput`, jadi border, state error/success, dan footer pesan selalu
konsisten di seluruh form.

## Anatomi

Root komponennya adalah `FieldShell` (dipakai bersama `PhoneInput`), jadi
class-nya berawalan `.uh-field`, bukan `.uh-input`.

- **`.uh-field`** - root. Membawa `data-size`, `data-state`
  (`default`/`error`/`success`), `data-full-width`.
- **`.uh-field__label-row`** dan **`.uh-field__label`** - baris label di atas
  kolom, ditambah **`.uh-field__required`** (asterisk dekoratif -
  `aria-required` di elemen input yang membawa arti sebenarnya).
- **`.uh-field__control`** - kotak berbingkai yang membungkus input dan
  adornment. Membawa `data-disabled`, `data-readonly`, `data-filled`; ini
  yang mengubah warna border saat hover/focus/error/success.
- **`.uh-field__input`** - elemen `<input>` native itu sendiri, transparan,
  mewarisi tipografi dari `.uh-field[data-size]`.
- **`.uh-field__icon`** - pembungkus `leftIcon`/`rightIcon`, selalu
  `aria-hidden`.
- **`.uh-field__action`** - tombol adornment (clear atau toggle password),
  membawa target sentuh 44px lewat pseudo-element `::after` meski ikonnya
  lebih kecil.
- **`.uh-field__footer`**, **`.uh-field__message`**, **`.uh-field__counter`**
  - baris di bawah kolom untuk helper/error/success text dan penghitung
    `maxLength`.

## Aksesibilitas

**Peran ARIA:** tidak ada peran eksplisit - `<input>` native sudah membawa
semantik yang benar, dihubungkan ke `<label>` lewat `htmlFor`/`id`.

Komponen ini tidak menambah keyboard handler kustom di atas semantik native
`<input>` - semua navigasi (Tab masuk/keluar, mengetik, seleksi teks) adalah
perilaku bawaan browser. Yang ditambahkan hanya target keyboard untuk dua
tombol adornment:

**Catatan screen reader:**

- `aria-invalid="true"` hanya muncul saat `errorMessage` terisi; pesan error
  dibaca lewat `role="alert"` sehingga diumumkan segera, sementara helper
  text dan success message dibaca lewat `aria-describedby` tanpa
  menginterupsi.
- Penghitung karakter (`.uh-field__counter`) bersifat dekoratif
  (`aria-hidden`) - batasnya dinyatakan sekali lewat `characterLimitLabel`
  yang tersembunyi visual, bukan diumumkan ulang di setiap ketikan.
- Tombol clear dan toggle password selalu punya `aria-label` sendiri
  (`clearLabel`, `showPasswordLabel`/`hidePasswordLabel`) - nama tombol
  toggle berubah sesuai state supaya selalu menjelaskan aksi berikutnya,
  bukan kondisi sekarang.
- `disabled` memakai atribut native `disabled` (bukan `aria-disabled`),
  karena field kosong yang dinonaktifkan memang tidak seharusnya
  mengirimkan nilai saat form displit - beda dengan `Button`, yang harus
  tetap bisa dijangkau keyboard.

**Wajib disediakan konsumen:**

- `label` - selalu string, tidak ada default yang masuk akal.
- `clearLabel`/`showPasswordLabel`/`hidePasswordLabel` saat field dipakai
  di luar bahasa Inggris - defaultnya bahasa Inggris, tapi bisa dioverride
  per pemanggilan.
- `characterLimitLabel` kalau pesan default (`Maximum ${max} characters`)
  perlu diterjemahkan.

## Catatan i18n

Malay dan Indonesian umumnya 15-30% lebih panjang dari English untuk label
dan helper text yang setara ("Passport Number" → "Nombor Pasport" / "Nomor
Paspor"). Label field tidak dipotong atau di-`ellipsis`-kan - baris label
(`.uh-field__label-row`) membiarkan teks yang lebih panjang membungkus ke
baris berikutnya secara alami, begitu juga `helperText`/`errorMessage`/
`successMessage`. Story `TextExpansion` membandingkan ketiga bahasa
berdampingan di kolom 280px, lebar yang kira-kira sama dengan satu kolom
form di layar ponsel kecil - di situlah label akan membungkus lebih dulu
kalau memang akan membungkus:
