# Rating

Dua mode dari satu komponen, dipilih lewat prop mana yang diisi - tidak
pernah lewat saklar "mode" eksplisit. Kirim `value` saja: skor dekoratif,
`role="img"`, dengan pengisian bintang yang benar-benar proporsional (4.3
dari 5 mengisi 86%, bukan dibulatkan ke empat setengah bintang). Tambahkan
`onChange`, `defaultValue`, atau `readOnly`: pemilih bintang,
`role="radiogroup"` dengan satu radio native per bintang - navigasi panah,
fokus, dan roving tabindex semuanya gratis dari browser, tidak ada yang
ditulis manual. Bintang terisi memakai warna `color.rating.filled`
(orange-600) di kedua tema, token khusus yang diperiksa terhadap rasio
kontras ikon 3:1, bukan rasio teks 4.5:1 yang lebih ketat.

## Aksesibilitas

**Peran ARIA:** mode tampilan memakai `role="img"` dengan skor lengkap
sebagai `aria-label` (mis. "4.5 out of 5, 812 reviews") - bintangnya sendiri
`aria-hidden` karena kalimat itu sudah membawa makna yang sama. Mode input
memakai `role="radiogroup"` dengan satu `<input type="radio">` native per
bintang, masing-masing diberi nama sendiri ("3 stars") lewat label
tersembunyi visual - independen dari bentuk glyph bintangnya.

**Catatan screen reader:**

- Mode tampilan diumumkan sebagai satu kalimat lewat `label` (bisa
  dioverride untuk terjemahan) - bukan sederet bintang tanpa makna.
- Mode input memberi setiap radio nama sendiri lewat teks tersembunyi
  visual (`starWord`, mis. "1 star" / "3 stars"), jadi nilai yang diumumkan
  tidak bergantung pada bentuk SVG bintangnya.
- `readOnly` diumumkan lewat `aria-readonly="true"` pada radiogroup -
  kontrolnya tetap fokusable dan namanya tetap terbaca, hanya perubahan yang
  diblokir di handler `onChange`.
- `disabled` memakai atribut `disabled` native pada setiap radio - berbeda
  dari `Chip`/`Button`, karena semantik radiogroup native sudah menangani
  keluar dari tab order dengan benar saat memang dimaksudkan tidak bisa
  diisi sama sekali.

**Wajib disediakan konsumen:**

- `groupLabel` di mode input saat dipakai di luar bahasa Inggris atau saat
  ada lebih dari satu Rating input di halaman yang sama - defaultnya
  "Rating", tidak cukup unik untuk membedakan beberapa pemilih sekaligus.
- `label` (fungsi kalimat) di mode tampilan kalau ingin diterjemahkan -
  defaultnya bahasa Inggris ("4.5 out of 5, 812 reviews").
- `onChange` yang benar-benar menyimpan nilai baru saat dipakai terkontrol
  (`value` + `onChange`) - komponen tidak menyimpan skor di luar sesi
  render itu sendiri; tanpa penyimpanan di sisi pemanggil, pilihan
  pengguna hilang begitu komponen di-render ulang.
