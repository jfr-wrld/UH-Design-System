# ProgressBar

Menunjukkan seberapa jauh sebuah proses berjalan - unggah file, form
multi-langkah, atau pemrosesan yang durasinya tidak diketahui. Mode
`indeterminate` menukar track menjadi garis-garis bergerak alih-alih angka
yang tidak nyata, jadi pemanggil tidak pernah dipaksa menampilkan persentase
palsu hanya karena butuh sesuatu untuk ditampilkan.

## Aksesibilitas

**Peran ARIA:** `role="progressbar"` mengikuti pola WAI-ARIA progressbar.
`aria-valuemin` dan `aria-valuemax` selalu ada. Pada mode determinate,
`aria-valuenow` dan `aria-valuetext` (persentase yang sudah diformat, mis.
"60%") ikut disertakan. Pada mode `indeterminate`, keduanya **sengaja
dihilangkan sepenuhnya** - bukan diisi 0 atau nilai lain - karena angka yang
tidak nyata lebih buruk daripada tidak ada angka sama sekali.

Nama aksesibel elemen selalu berasal dari `label`: kalau `showLabel` aktif,
elemen visual label itu yang menjadi `aria-labelledby`; kalau tidak,
`label` tetap dipasang lewat `aria-label` walau tidak tergambar di layar -
`label` wajib diisi, tidak ada default yang masuk akal untuk sebuah bar
tanpa nama.

**Interaksi keyboard:** tidak ada. ProgressBar adalah elemen status murni,
bukan kontrol - tidak menerima fokus dan tidak punya keyboard handler.

**Catatan screen reader:**

- Persentase yang diumumkan (`aria-valuetext`) dan yang ditampilkan lewat
  `showValue` sama-sama diformat lewat `Intl.NumberFormat` untuk `locale`
  yang diberikan - bukan string buatan tangan, supaya tanda persen dan
  urutan digit mengikuti konvensi bahasa tersebut (mis. angka Arab-Indic
  untuk `locale="ar"`).
- Lebar visual fill dihitung dari fraksi mentah (`value / max`), terpisah
  dari teks persentase yang diformat - format persen sebuah locale bukan
  satuan panjang CSS, jadi keduanya tidak boleh saling menggantikan.

**Wajib disediakan konsumen:**

- `label` - satu-satunya prop wajib; tanpa ini bar tidak punya nama sama
  sekali untuk screen reader.
- `value`/`max` saat determinate, atau `indeterminate` saat durasi memang
  tidak diketahui - pilih salah satu secara sadar, jangan biarkan default
  `value=0` terlihat seperti progres yang belum mulai padahal sebenarnya
  tidak diketahui.
