# Checkbox

A boolean choice that is part of a form and takes effect only when that form
is submitted - agreeing to booking terms, opting into an add-on, marking one
item among several as selected. The box itself is 20px so a column of
options still reads as a list, but the pointer target is a full 44px laid
over the box rather than inflating it, and the focus ring sits on the box
rather than the whole row so it says exactly what is focused.

## Aksesibilitas

**Peran ARIA:** tidak ada peran eksplisit - `<input type="checkbox">` native
sudah membawa role `checkbox`. Saat `indeterminate` aktif, platform
melaporkan `aria-checked="mixed"` lewat properti DOM `indeterminate`, bukan
lewat atribut `aria-checked` yang ditulis tangan - menulis atributnya sendiri
akan membuat satu elemen punya dua sumber kebenaran yang bisa saling
bertentangan.

**Catatan screen reader:**

- Label diklik lewat elemen `<label>` yang di-`htmlFor` ke id input, jadi
  mengklik teks label sama efeknya dengan mengklik boks - target sentuh
  paling umum yang dipakai orang.
- `description` (jika ada) ditautkan lewat `aria-describedby`, terbaca
  screen reader setelah nama checkbox, bukan sebagai baris teks lepas.
- `error` mengeset `aria-invalid="true"` di input - state error tidak
  boleh hanya mengandalkan warna karena boks glyph-nya sendiri hanya
  berubah warna tanpa bentuk yang berbeda.
- Boks visual (`.uh-choice__box`) selalu `aria-hidden` - dia murni
  mencerminkan state input lewat CSS, sehingga screen reader membaca input
  aslinya dan tidak pernah membaca boks dua kali.

**Wajib disediakan konsumen:**

- `label` - wajib secara tipe TypeScript, karena nama checkbox tidak punya
  default yang masuk akal.
- Relasi anak-parent untuk `indeterminate` harus dihitung sendiri oleh
  pemanggil (mis. dari jumlah item anak yang tercentang) - Checkbox tidak
  tahu tentang checkbox lain, dia hanya menampilkan apa pun boolean yang
  diberikan lewat prop.
